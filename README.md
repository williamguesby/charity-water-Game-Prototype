# Drop by Drop

A small charity: water-inspired browser game. Move the bucket to catch clean drops and dodge dirty-water obstacles before the 30-second timer runs out.

## Play

Open `index.html` in a browser, or serve this folder with any static web server. Press **Start game**, then drag the bucket anywhere in the playfield to catch blue drops and avoid brown dirty-water drops. You can also move the bucket in any direction with the arrow keys or **W/A/S/D**. Clean drops add 10 points; catching dirty water subtracts 30 (the score cannot go below zero), while dirty drops that hit the ground do not count as missed. Reach 50 points before time runs out to win and trigger a confetti celebration. Use **Reset game** to start a fresh round.

The game is built with plain HTML, CSS, and JavaScript; it has no build step or runtime dependencies.
